# 工作流

```
                ┌──────────── 入口 ─────────────┐
   人 → GUI 工作台 (app.py)        Claude → skill (skills/short-video-factory)
                └──────────────┬────────────────┘
                               ↓  同一套代码(svf/)
 ① 入库  ingest_proxy(60fps 预览/HDR) → ingest_sheets(联系表) → Claude 打标签 → 素材索引.json
         ingest_transcribe(口播转写) → 挑博主原声句    ingest_mingbaika(明白卡 → 白名单候选)
 ② 模板  参考爆款逐帧拆解 → templates/*.json + 蒸馏.md
 ③ 文案  数据/文案池.json(人可编辑) → batch.py 按 5 风格组合,优先用少用的说法
 ④ 合规  数字白名单(明白卡) / 禁用词 / 风险素材 —— 不过就不出片
 ⑤ 配音  剪映 SAMI(缓存),数字转中文读法,按风格加速
 ⑥ 渲染  render.py:按句切镜头 → 60fps 缓推/平移(预放大防抖) → 转场 → 字幕/大字卡/标题/贴纸 → 配乐 → NVENC
 ⑦ 质检  qc.py:响度 / 黑帧 / 时长 / 抽样逐句转写核对数字 / 抽帧联系表 / 镜头重合率
 ⑧ 交付  成片/批次_xxx/ + 报告.md + 清单.csv + 剪映草稿(精修用)
```

## 项目目录结构(不进 git)
```
<项目>/
  project.json          品牌/白名单/禁用词/数字读法/素材源/配音/音乐/博主片段/清单理由
  素材/ 预览60/ 联系表/
  数据/ 素材索引.json  文案池.json  明白卡.json  口播转写.json  tts_cache_sami/
  配乐/                 音乐文件(剪映云端下载)
  模板/                 (可选)项目自带模板,否则用仓库 templates/
  脚本/ bNNN.json       生成的脚本(不要手改,改源头)
  成片/ bNNN.mp4  批次_xxx/
```

## 常用命令
| 目的 | 命令 |
|---|---|
| 启动工作台 | `.venv/Scripts/python app.py` |
| 出 N 条 | `svf/batch.py --n N --start S -j 3 --qc-sample 0.2` |
| 只要某些风格 | `--styles S1,S4` |
| 预演文案重复度 | `--dry` |
| 30fps(更快) | 环境变量 `AVD_FPS=30` |
| 单条重渲 | `svf/render.py b601` |
| 单条剪映草稿 | `svf/jy_draft.py b601` |
| 质检 | `svf/qc.py b601 b602`(`QC_ASR=b601` 只转写部分) |
